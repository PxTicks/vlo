# Optional SAM-Audio install for the backend virtual environment.
# SAM-Audio owns VCS-only dependencies such as dacvae, ImageBind, and
# perception-models, so keep them attached to the upstream package instead of
# listing them as bare PyPI requirements in backend/requirements.txt.
#
# Install this file with `--overrides backend/overrides-sam-audio.txt`; the
# protobuf floor SAM-Audio needs lives there, because dacvae caps protobuf below
# 3.20 and a requirement cannot lift another package's cap. Every installer path
# (install.sh, install.bat, the in-app capability installer) passes it.
#
# Requires Python >=3.11.
sam_audio @ git+https://github.com/facebookresearch/sam-audio.git
